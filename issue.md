## Role Admin

# Menu Input Manual
1. Modul Input Manual, setelah buka kamera, button untuk ambil gambar tidak tampil
2. Waktu kunjungan seharusnya 13:22. Di data tertulis 06:21. Timezone gunakan Asia/Jakarta jika masalahnya di Timezone
3. Tambahkan juga ketika input manual, ada pilihan untuk agenda yang sudah diinputkan Admin atau untuk tamu bebas.
4. Label NIK(No. KTP) diubah menjadi NIP / NIK (No. KTP)

# Menu Manajemen Agenda
1. Data Agenda tidak tampil di datatable setelah selesai dibuat. padahal di database masuk.
2. waktu mulai dan selesai gunakan format YYYY-MM-DD HH:mm. Saat ini tampil nya : 2026-05-26T12:00

# Menu Laporan & Export
1. Ditambahkan untuk cetak peserta/tamu pada agenda yang sudah dibuat Admin. Isi tamu terpisah dengan tamu reguler yang tanpa ada agenda.
